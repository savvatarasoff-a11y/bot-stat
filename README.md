# bot-stat — Telegram-бот с рассылкой и статистикой

* **Скачивание видео из TikTok**: пользователь присылает ссылку (`tiktok.com`, `vm.tiktok.com`, `vt.tiktok.com`), бот отвечает видеофайлом. Используется [yt-dlp](https://github.com/yt-dlp/yt-dlp); видео больше 50 МБ Telegram боту отправить не даёт. Чтобы видео не лагали в Telegram, бот берёт формат H.264, а если TikTok отдал H.265 — перекодирует его через ffmpeg (ставится скриптом установки) и переносит индекс в начало файла для мгновенного старта. Пользователи видят только загрузчик: статистика, рассылка и их команды доступны лишь админу.

* Запоминает все свои чаты: пользователей, которые написали боту, а также группы и каналы, куда его добавили.
* **Рассылка** по всем чатам: админ присылает сообщение (текст, фото, видео, кнопки, что угодно), бот копирует его каждому.
* После рассылки приходит отчёт: сколько доставлено, сколько не доставлено, сколько всего обработано. Цифры считаются по реальным ответам Telegram.
* Кто заблокировал бота или удалил аккаунт, помечается неактивным и больше не получает рассылку. Если человек снова напишет боту, он вернётся в список.
* Учитываются флуд-лимиты Telegram: по умолчанию 25 сообщений в секунду, при `RetryAfter` бот ждёт и повторяет отправку.
* **Статистика**: пользователи, группы, сколько чатов получит рассылку, прирост и активность, источники по параметру `/start`, последние рассылки.
* **Настраиваемая статистика**: админ кнопками выбирает, какие блоки показывать, за какие периоды (сутки / неделя / месяц) считать новых и активных, сколько источников и рассылок выводить, и задаёт свой заголовок. Настройки хранятся в базе и общие для всех админов.
* **Изменение цифр**: в настройках кнопка «🔢 Изменить цифры». Для каждого показателя можно задать точное значение (`1500`) или поправку к реальному (`+500`, `-20`), а потом вернуть реальные цифры. Если поправлено «Получат рассылку», отчёт после рассылки, прогресс и «Последние рассылки» считаются так, будто рассылка шла на столько чатов (доставленные и недоставленные — в реальной пропорции). Поправки «Доставлено / Не доставлено в рассылке» добавляются сверху и применяются к отчёту после каждой рассылки и к «Последним рассылкам» в /stats (в базе хранятся реальные цифры).
* **Отчёт после рассылки** настраивается кнопкой «📨 Отчёт после рассылки» в настройках статистики: какие строки показывать (доставлено, не доставлено, всего, заблокировали) и добавлять ли к отчёту статистику бота с выбранными блоками, заголовком и правками цифр. Если рассылка прервётся ошибкой, отчёт по уже отправленным всё равно придёт.

Админ: `5349009098` (задан в `bot/config.py`, можно переопределить переменной `ADMIN_IDS`).

## Команды админа

| Команда | Что делает |
|---|---|
| `/admin` | Панель с кнопками «📨 Рассылка» и «📊 Статистика» |
| `/broadcast` | Бот отвечает «✉️ Введите текст для рассылки:», следующее сообщение уходит всем |
| `/stop` | Остановить идущую рассылку (отчёт придёт по уже отправленным) |
| `/stats` | Статистика (кнопки «🔄 Обновить» и «⚙️ Настроить») |
| `/stats_settings` | Настройка статистики: блоки, периоды, лимиты, заголовок, сброс к умолчаниям |
| `/cancel` | Отменить ввод текста рассылки или заголовка |

Во время больших рассылок каждые 5000 отправок приходит прогресс. Рассылка на 100 000 чатов при 25 сообщений/с идёт около 70 минут.

## Хостинг на Aeza

1. Создайте бота у [@BotFather](https://t.me/BotFather) (`/newbot`) и скопируйте токен.
2. Купите VPS на Aeza с Ubuntu 22.04/24.04 (хватит самого дешёвого тарифа) и подключитесь по SSH: `ssh root@IP`.
3. Выполните одну команду, подставив токен:
   ```bash
   curl -fsSL https://raw.githubusercontent.com/savvatarasoff-a11y/bot-stat/main/deploy/install.sh | bash -s -- 123456:AAH...
   ```
   Скрипт ставит Python, клонирует репозиторий в `/opt/bot-stat` и запускает systemd-сервис `bot-stat`. Сервис стартует вместе с сервером и перезапускается при падении.
4. Напишите боту `/admin`.

**Обновить** до новой версии из GitHub: та же команда без токена (`... | bash`). База (`/opt/bot-stat/data/bot.db`) сохраняется.

**Логи:** `journalctl -u bot-stat -f`. **Перезапуск:** `systemctl restart bot-stat`.

**Резервная копия базы:** `cp /opt/bot-stat/data/bot.db ~/bot-$(date +%F).db`

### Через Docker (вместо systemd)

```bash
git clone https://github.com/savvatarasoff-a11y/bot-stat && cd bot-stat
docker build -t bot-stat .
docker run -d --name bot-stat --restart=always -e BOT_TOKEN=123456:AAH... -v bot-stat-data:/data bot-stat
```

## Локально

```bash
pip install -r requirements-dev.txt
cp .env.example .env   # вписать BOT_TOKEN
python -m bot.main
python -m pytest -q    # тесты
```
